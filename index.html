What I've Built

LÖVE2D Lua CS50

Breakout

A full Breakout remake built from scratch following Harvard's CS50 Game Development course. Features a spritesheet-based rendering system using Quads, a particle explosion system on brick destruction, a complete state machine architecture, and a persistent file-based high score system — a feature the original CS50 project left unimplemented.

What I built: Ball physics and bounce angle calculation based on paddle velocity, AABB collision with penetration depth correction, tier-based brick damage system, level generation with randomised patterns, and file I/O for persistent leaderboards.

LÖVE2D Lua

Flappy Bird

A complete Flappy Bird clone built in LÖVE2D with custom assets. Implements two-layer parallax scrolling using modulo-based infinite scroll, frame-rate independent movement with delta time, and AABB collision detection between the bird and dynamically spawned pipes.

What I built: Infinite background and ground scroll using the modulo operator, gravity and flap physics tuned by feel, random pipe gap generation, bird rotation based on velocity, three game states (title, playing, game over).

Godot 4 GDScript

The Wizard

A top-down arcade collector built in Godot 4. The player collects potions against a 30-second countdown timer, with potions respawning at random screen positions on collection. My first completed Godot project — built to learn the engine's node system, Area2D physics, and signal-based collision detection.

What I built: CharacterBody2D player with dynamic boundary clamping, Area2D coin scenes with collision signals, preload-based scene instantiation, Timer node with game over transition, call_deferred fix for physics callback spawning.

LÖVE2D Lua CS50

Pong

A Pong remake built as part of Harvard's CS50 Game Development course. Implements two-player gameplay and a simple AI opponent. My first complete game — where I learned delta time movement, AABB collision, and the fundamentals of a game loop.

What I built: Frame-rate independent paddle and ball movement, AABB collision detection, ball angle variation on paddle hit, AI opponent with deliberate error margin to keep gameplay fair.

// ABOUT ME

Who I Am

I'm Ted Gaturu, a Year 2 BSc Gaming Animation Technology student at KCA University in Nairobi, Kenya. I build games under my studio brand Teganjo Studios (TGN) — targeting a career as a Junior Gameplay Programmer with a long-term goal of building a financially sustainable, remote-first game studio.

I got into game dev because I wanted to understand how the things I played actually worked. That curiosity drives how I learn — I type every line of code by hand, understand every system before moving forward, and build things I can explain in full. I use AI tools like Claude to accelerate learning, not replace understanding.

Outside of game dev, I work at my family's hardware shop most of the week — which means everything in this portfolio was built in early mornings, late evenings, and Sundays. Shipped under real constraints.
